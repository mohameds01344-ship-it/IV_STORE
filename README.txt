IV_STORE — FRONT-END STORE
==========================

تشغيل الموقع:
1) فك ضغط الملف.
2) افتح المجلد باستخدام VS Code.
3) افتح index.html مباشرة في المتصفح. ولو حبيت تستخدم VS Code تقدر تشغّله بـ Live Server كمان.
4) للنشر المجاني: ارفع محتويات المجلد على Netlify أو Cloudflare Pages.

تعديلاتك الأساسية:
- config.js: رقم واتساب البراند، روابط Instagram/Facebook/TikTok، أسعار الشحن لكل محافظة.
  اكتب رقم واتساب بصيغة دولية بدون + أو مسافات، مثال: 2010XXXXXXXX.
- products.js: المنتجات منفصلة واحد واحد. غيّر الاسم والسعر والمقاسات والتصنيف والصورة وحالة المخزون.
- assets/: صور المنتجات واللوجو. لاستبدال صورة منتج، استبدل الملف بنفس الاسم أو عدّل مسار image في products.js.

التصنيفات:
hoodie = هودي
sweatshirt = سويت شيرت
polo = بولو / ياقة وأزرار

ملاحظات:
- الأسعار الحالية تجريبية وقابلة للتعديل.
- أسعار الشحن تقديرية كبداية وقابلة للتعديل في config.js.
- الطلبات تُرسل إلى واتساب. لا توجد قاعدة بيانات أو لوحة تحكم أو دفع إلكتروني؛ السلة تحفظ محلياً في متصفح العميل.
- روابط السوشيال وأرقام التواصل متروكة فارغة حتى تضيف بياناتك.
- لتعديل النصوص العربية والإنجليزية، افتح app.js وابحث عن translations.
